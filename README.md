## 리포트 구성

1. **Executive Summary** — 시장 스탠스와 당일 행동
2. **전일 판단 복기** — 채점 시계 원칙(익일 채점 / 1개월 보류)에 따른 검증
3. **Market Briefing** — KR·US 지수, 수급·업종, 원인-해소 매칭
4. **Risk Register** — 진행형 리스크 R1~R8 당일 상태와 전일 대비 변화
5. **Catalysts** — 이번 주 이벤트와 사전 대응
6. **Portfolio Analysis** — 종목별 의견 · Confidence(1~5) · 상승/횡보/하락 확률 · 반증 조건 · 투자 대가 3중 체크(버핏·달리오·막스)
7. **Watchlist Ranking** / **Rebalancing Note**
8. **Trading Plan** — 트리거 검산, 매수 금지 신호, 실행 계획
9. **Self-Audit** — 커버리지 점검과 미확인 항목 추적

## 방법론

- **급락 트리거**: 전일 종가 × 0.97 도달 시 계획 자금 25% 이하 1차 진입 검토. 판정은 종가 기준
- **매수 금지 신호**: 중앙은행 매파 서프라이즈 / 빅테크 AI capex 축소 / 브렌트유 $105+ — 하나라도 발생 시 관망
- **분할 원칙**: 일시금 진입 금지, 최소 3분할(고변동 국면 4분할 이상)
- **미확인 표기**: 교차 검증되지 않은 데이터는 추정하지 않고 "미확인"으로 명시
- **채점 시계 일치**: 1개월 시계 확률은 1개월 후에만 채점하고, 익일 복기에서는 근거 유효성만 판정
